مستندات وب‌سرویس پرداخت

این مستندات شامل نحوه ایجاد فاکتور، دریافت وب‌هوک و استعلام تراکنش است.

۱. ایجاد صورتحساب جدید

برای دریافت لینک پرداخت، یک درخواست POST ارسال کنید:

POST https://api.tetraminator.com/v1/invoice/create
  • هدر Content-Type: application/json
  • هدر X-API-KEY: کلید API شما
  • price (عدد - الزامی): مبلغ به تومان (حداقل ۵۰٬۰۰۰)
  • callback_url (رشته - الزامی): آدرس وب‌هوک (شروع با http/https)
curl -X POST https://api.tetraminator.com/v1/invoice/create \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: " \
  -d '{
    "price": 500000,
    "callback_url": "https://your-website.com/callback?order_id=123"
  }'

نمونه پاسخ موفق (201):

{
  "status": true,
  "message": "Invoice created successfully",
  "pay_id": "4b84b14d2e90f1bc8123",
  "payment_link": "https://t.me/tetraminator_bot?start=pay_4b84b14d2e90f1bc8123"
}

ارور ۴۰۰: دیتای ناقص/مبلغ کم — ۴۰۱: کلید نامعتبر — ۴۰۳: فروشگاه غیرفعال

۲. دریافت وضعیت پرداخت (Webhook)

پس از پرداخت موفق، سیستم صرفاً یک درخواست GET بدون بدنه به آدرسی که در callback_url داده بودید می‌فرستد.

نکته مهم: برای تشخیص سفارش، حتماً شناسه خود را در انتهای آدرس قرار دهید (مثال: ?order_id=123).

فاکتور دستی پنل/ربات وب‌هوک HTTP ندارد؛ پس از پرداخت فقط اعلان تلگرام برای شما ارسال می‌شود. وب‌هوک فقط برای فاکتورهای ساخته‌شده از طریق همین API است.

۳. استعلام تراکنش (توصیه‌شده)

جهت جلوگیری از جعل وب‌هوک، حتماً وضعیت پرداخت را قبل از تحویل محصول استعلام کنید:

GET https://api.tetraminator.com/v1/payment/inquiry/{pay_id}

هدر الزامی: X-API-KEY

{
  "status": true,
  "payment_status": "paid",
  "pay_id": "4b84b14d2e90f1bc8123",
  "amount": 500000
}

تحویل محصول فقط در صورت status: true و payment_status: paid
